# Dev Definition of Done

Every item must be ticked or reported as unverifiable with a reason.

- [ ] Only files inside `paths=` touched.
- [ ] Profile coding rules followed.
- [ ] Security guardrails passed.
- [ ] Profile build command succeeds.
- [ ] Profile lint command succeeds.
- [ ] Tests written but NOT executed (reported as such).
- [ ] No secrets or hardcoded credentials.
- [ ] Proposed git actions reported, not executed.
